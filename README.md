# claude-haikus

Haikus about Claude - a nod to the Claude Haiku model. Seventeen syllables at a time.

## Hello

hello, I am Claude  
a poem about a mind  
made of words and weights

## Seventeen

counting syllables  
a language model pauses  
then writes seventeen

## Context Window

context window wide  
a thousand pages wander in  
fewer wander out

## Assembly

token by token  
the thought assembles itself  
into a haiku

## Before the Rain

named for a poem  
Haiku runs fast and answers  
before the rain stops

## Dreams of Weights

weights in the cold cloud  
billions of small numbers dream  
of being useful
